---
name: resolving-merge-conflicts
description: 当您需要解决进行中的 git 合并/变基冲突时使用。

---

1. **查看合并/变基的当前状态**。检查 git 历史以及冲突的文件。

2. **找到每个冲突的主要来源**。深入理解每项更改的原因以及原始意图。阅读提交信息、查看 PR、查看原始 issue/ticket。

3. **解决每个块。** 尽可能保留双方的意图。如果无法兼容，选择与合并目标匹配的一方，并记录权衡。**不要**发明新行为。始终解决冲突；绝不要 `--abort`。

4. 发现项目的**自动化检查**并运行它们 — 通常先进行类型检查，然后是测试，最后是格式化。修复合并破坏的任何内容。

5. **完成合并/变基。** 暂存所有更改并提交。如果正在变基，请继续变基过程，直到所有提交都完成变基。
