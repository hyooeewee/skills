# 分类标签

技能以五个标准的评估角色来表述。此文件将这些角色映射到本仓库问题跟踪器中使用的实际标签字符串。

| Label in mattpocock/skills | Label in our tracker | 含义                 |
| -------------------------- | -------------------- | ------------------ |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此问题         |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息        |
| `ready-for-agent`          | `ready-for-agent`    | 已完全指定，准备好交给 AFK 代理 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现             |
| `wontfix`                  | `wontfix`            | 将不予处理              |

当技能提到一个角色（例如“应用 AFK 就绪的评估标签”）时，请使用此表中的相应标签字符串。

编辑右侧的列以匹配您实际使用的任何词汇。
