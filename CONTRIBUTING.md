# 贡献指南

每个问题都将根据 [`SCOPE.md`](./SCOPE.md) 中的标准进行评判。请先阅读它。

## 各类请求的去向

| 您有               | 前往                                                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 技能中的 Bug         | [Bug 报告](https://github.com/mattpocock/skills/issues/new?template=bug.yml)                                                      |
| 对现有技能的更改         | [想法或反馈问题](https://github.com/mattpocock/skills/issues/new?template=idea.yml)                                                    |
| 问题，或「我该如何……？」    | [Discussions: Q\&A](https://github.com/mattpocock/skills/discussions/categories/q-a)                                            |
| 新技能的想法，或要捐赠的技能   | [Discussions: Ideas](https://github.com/mattpocock/skills/discussions/categories/ideas)                                         |
| 对其他测试框架或问题追踪器的支持 | [Discussions: Ideas](https://github.com/mattpocock/skills/discussions/categories/ideas)，阅读完 [`.out-of-scope/`](./.out-of-scope) |

拉取请求仅对协作者开放，因此请在问题中描述修复方案。

## 由 AI 编写的问题

欢迎代理协助，但您发布问题，所以您对其负责：

* **每个问题只解决一个问题。** 一次会话中的多个发现应拆分为多个问题，或不提交。
* **简短。** 如果超出一屏，请精简。
* **先复现。** 复现问题的步骤应置于任何分析之前。
* **不粘贴规格。** 不要粘贴完整的提案、计划或重写的 `SKILL.md` 文件。描述问题；修复方案由我们设计。
* **不是您项目的问题。** 如果您的代理在此提交您自己项目的规格或工单，说明仓库选错了。请在您的项目中运行 `/setup-matt-pocock-skills`。
