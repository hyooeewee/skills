# 仅为硬依赖显式使用 `/setup-matt-pocock-skills` 指针

工程技能依赖于由 `/setup-matt-pocock-skills` 初始化的仓库级配置（问题追踪器、分类标签词汇、领域文档布局）。有些技能没有该配置就无法有意义地运行：它们必须发布到特定的问题追踪器或应用特定的标签字符串。其他的技能仅用它来提高输出质量（词汇、ADR 意识），并在没有它的情况下优雅降级。

我们将这些技能分为**硬依赖**和**软依赖**技能：

* **硬依赖**（`to-tickets`、`to-spec`、`triage`）：包含一个显式的一行提示：*"……应该已经提供给你；如果没有，请运行 `/setup-matt-pocock-skills`。"* 没有映射，输出就是错误的，而不仅仅是模糊。
* **软依赖**（`diagnose`、`tdd`、`improve-codebase-architecture`）：仅在模糊的叙述中引用“项目的领域词汇表”和“你所接触区域的 ADR”。如果文档不存在，该技能仍然有效；输出只是不那么精确。

这种划分使软依赖技能保持轻量（token-light），并避免将设置指针在非关键位置进行生搬硬套。
